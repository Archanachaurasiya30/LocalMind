# LocalMind 0.8.0

A calmer chat workspace, clearer model controls, and an optional media studio.

## What's new

- Soft light and dark backgrounds, subtle spotlight surfaces, and glass-style action buttons with visible keyboard focus and reduced-motion support.
- A redesigned composer with an response-mode picker, visible context chips, voice controls and editable starter prompts.
- Full-window and mini chat share the conversation and draft. Expand, pin or minimize the compact window without restarting a response.
- A Media workspace with persistent job history, progress, failure details and native image/video export.
- Reviewed Runway Gen-4 Turbo video submission with a profile-scoped OS credential store, source-image and price review, a local $50 monthly reservation limit, and recovery that never silently resubmits a paid generation.
- An optional image worker with separate model downloads, one active image job, cancellation, checksum validation and isolation from chat. Image generation remains disabled by default after the earlier visual-quality trial failed.
- Built-in planner and synthetic repair-recipe tools, plus an explicitly enabled, owned MCP test server. Third-party plugin execution and arbitrary MCP servers are not supported.
- Gmail uses read-only access and native credential storage. Existing connections require fresh authorization. Provider acceptance is still based on fixtures rather than a live Gmail account.
- A Windows local voice pilot using whisper.cpp and stock system voices. It remains disabled by default pending human microphone and playback acceptance.
- A new full-window desktop walkthrough with a browser player and fullscreen controls, linked from the README.

## Install

| Computer | Installer |
| --- | --- |
| Windows x64 | `LocalMind_0.8.0_x64-setup.exe` |
| macOS Intel, macOS 14+ | `LocalMind_0.8.0_x64.dmg` |
| macOS Apple Silicon, macOS 14+ | `LocalMind_0.8.0_aarch64.dmg` |
| Linux x64 | `.deb` or `.AppImage` |

The Python service and Ollama runtime are bundled. Chat models download separately; an existing local Ollama installation can be reused. Image/CUDA dependencies are optional and are not bundled. Docker is not required.

Updater bundles are signed with LocalMind's update key. Windows installers are not Authenticode-signed and macOS apps are not Apple-notarized. Verify downloads against `SHA256SUMS.txt`.

## Feature boundaries

Local chat, file retrieval, memory, projects and tasks work on each person's independent desktop profile. Web search, connectors and video generation contact their respective providers when used. There is no shared account service or automatic cross-device sync.

Video requires your own paid Runway API key and explicit approval for each request. Live provider generation, native media export acceptance and real generation through the new image worker remain pending; deterministic tests do not establish visual quality. Images and voice are experimental opt-in pilots. File repair apply/restore is a Windows pilot; other platforms can inspect previews. WhatsApp and iMessage remain unavailable.

See the [README](https://github.com/Swarneil1905/LocalMind#readme), [Media guide](https://github.com/Swarneil1905/LocalMind/blob/main/docs/media.md), and [voice guide](https://github.com/Swarneil1905/LocalMind/blob/main/docs/voice.md) for setup and limits.
